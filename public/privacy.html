Privacy Policy — HatakuBot

Last updated: October 13, 2026

Summary: HatakuBot is a personal project built and used only by its developer, Muhammad Hasbi Takumi. It connects to the developer's own Google Drive to help search and read files through a private Telegram bot. It is not offered to the public, and it does not sell or share data.

1. About this application

HatakuBot is a private assistant that runs on the developer's own computer. It receives messages from a single authorized Telegram account and can search, read, and organize files in the developer's own Google Drive account, as well as keep personal notes and reminders. The app is used by one person only (its owner).

2. Information the app accesses

When the owner signs in with Google, the app requests access to Google user data as follows:

  • Google Drive files and metadata (file names, folders, and file content) via the drive.readonly scope, used only to search and read files when the owner asks.
  • Files created by the app via the drive.file scope, used only to create or upload files and folders that the owner requests.
  • Telegram messages sent by the owner to the bot, used to understand and answer requests.

The app does not access Gmail, Contacts, Calendar, or any other Google service.

3. How the information is used

  • To search, list, read, and summarize the owner's Drive files on request.
  • To create folders or upload files on request.
  • To store the owner's own notes, to-do items, and reminders.

When the owner asks a question that needs AI, the relevant message and any file content the owner asked the bot to read may be sent to an AI model provider (Google Gemini API) in order to generate a response. This only happens in response to the owner's own request.

4. Storage and security

  • OAuth tokens and credentials are stored locally on the owner's computer, in files that are excluded from source control, and are never published.
  • Notes and settings are stored locally on the owner's computer.
  • The bot only responds to the owner's Telegram account; messages from any other account are rejected.
  • Actions that modify Google Drive require explicit confirmation from the owner.

5. Sharing and selling of data

The developer does not sell, rent, or share Google user data with third parties, and does not use it for advertising. Data is shared only with the service providers strictly needed to run the app as described above (Telegram to deliver messages, and the Gemini API to generate AI responses).

6. Google API Services User Data Policy

HatakuBot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Retention and deletion

The owner can delete local notes and tokens at any time by removing the app's data files. Access can be revoked at any time from the Google Account permissions page: myaccount.google.com/permissions.

8. Changes to this policy

This policy may be updated as the project changes. The date at the top shows the latest revision.

9. Contact

Questions about this policy can be sent to muhammadhasbi.t@gmail.com.
